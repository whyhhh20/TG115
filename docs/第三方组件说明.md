# 第三方组件说明

本部署器和服务端使用以下第三方软件或库：

- Paramiko：SSH/SFTP 客户端，LGPL-2.1；
- PyInstaller：Windows 单文件打包工具，GPLv2-or-later，带 Bootloader 特别例外；
- Telethon：Telegram MTProto 客户端，MIT；
- cryptg：Telegram 加密加速；
- psutil：系统资源监控，BSD-3-Clause；
- rclone：文件传输工具，MIT；在本项目中只作为 CloudDrive2 WebDAV 客户端使用
  （`cd2:` remote，`type=webdav`），不配置 Google `drive` 后端，也不执行
  `rclone authorize`；
- Docker / Docker Compose：容器运行环境；
- CloudDrive2：由 CloudDrive 官方提供的专有软件和 Docker 镜像，115 与 Google Drive 两条
  路线都通过它传输。

CloudDrive2 不包含在本地 EXE 内。部署器按照用户勾选，在 VPS 上从官方
`cloudnas/clouddrive2` 镜像仓库拉取；使用条件受 CloudDrive2 官方许可和会员规则约束。
115 和 Google Drive 的登录/授权都在 CloudDrive2 管理页由用户本人完成，本程序不保存、
不传输 Google OAuth token、client ID 或 client secret，也不直接请求 Google API。

正式版 1.5.0 交付包锁定以下镜像摘要：

```text
CloudDrive2：
cloudnas/clouddrive2@sha256:5491c21fb14a5774576515f8483ecdbe2780bf525985f426785b99488e7cc09d

Python 3.12 slim trixie：
python:3.12-slim-trixie@sha256:57cd7c3a7a273101a6485ba99423ee568157882804b1124b4dd04266317710de
```

摘要核对及 Trivy 0.72.0 高危/严重漏洞扫描日期：2026-07-29：

- CloudDrive2 锁定镜像：0 条 HIGH/CRITICAL 软件包记录；
- Python Trixie 锁定基础镜像：23 条（19 HIGH、4 CRITICAL），扫描时均无
  `FixedVersion`；这比同时扫描的 Bookworm 基础镜像少 1 条，CRITICAL 从 6 条降为 4 条；
- Python 依赖清单和构建依赖经 `pip-audit` 检查，0 个已知漏洞。

这些记录主要来自 Debian 基础系统软件包，不表示 23 条都能被本 Bot 的输入路径触发，
但也不能据此宣称镜像“零风险”。镜像扫描同样不等于对 CloudDrive2 专有程序本身完成
源代码审计。部署器通过非 root Bot 容器、只读根文件系统、移除 capabilities 和仅允许
本人 Telegram ID 等措施降低可利用面；CloudDrive2 特权容器的风险仍然存在。

普通重新部署不会自动切换到仓库中的新镜像；
升级镜像需要更新摘要、重新运行测试并生成新的交付版本。

完整 Python 和脚本源代码随交付包提供，便于审查、修改和重新构建。
